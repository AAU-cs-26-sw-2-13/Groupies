## Setup
- Needs a running MySQL server
- Configure the .env to select the MySQL server with the correct credentials.

        MYSQL_HOST=
        MYSQL_PORT=
        MYSQL_USER=
        MYSQL_PASSWORD=
        MYSQL_DATABASE=

        PORT=
        NODE_ENV=development

        MYSQL_DROPALL=true ## Drops database and runs migrations from scratch
        TESTING_MOCKDATA=1000 ## Amount of users to mock data for
